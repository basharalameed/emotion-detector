## الوصف
تم بناء خادم تشغيل حي جديد `scripts/run_live_nv.py` يستخدم واجهة NVIDIA NIM API
(نموذج Llama 3.3 70B حقيقي) بدلاً من سيرفر Watson الذي لا يُوصل إلا من داخل
مختبرات الدورة (عناوين خاصة 10.241.x.x).

- نفس واجهة الويب والسلوك الحرفي لواجب الدورة (نفس صفحة index ومسار /emotionDetector
  ونفس صيغة المخرجات).
- استخراج درجات العواطف الخمس + العاطفة السائدة من رد النموذج بصيغة JSON مع
  احتياطي استخراج عبر Regex.
- المفتاح يُقرأ من متغير بيئة NV_API_KEY أو من ملف `.env` المحلي (محمي
  في .gitignore — لم يُرفع لأي مستودع أبداً).
- إصلاح جذري: الـ patch على `requests.post` كان يعدّل الوحدة المشتركة فيصيب
  الاتصال الداخلي بالتكرار اللانهائي — حُل بحفظ المرجع الأصلي `_real_post`
  قبل بدء الـ patch (طبّق أيضاً على run_live_hf.py).
- pylint: 10.00/10 لجميع الملفات؛ دعم متغير PORT للنشر السحابي.

## الأهمية والتأثير
- يجعل "التجربة الحقيقية" ممكنة من حاسوب المستخدم دون مختبر الدورة ودون أي
  تحميلات ثقيلة (لا حزم جديدة، requests/flask فقط).
- نتائج موثقة فعلياً: "I am so glad this happened" → joy 0.93؛
  "I am really mad about this" → anger 0.85 (اختبارات حية ناجحة HTTP 200).
- ملفات النشر السحابي (space/) أضيفت سابقاً لنشر التطبيق على Hugging Face Spaces.
